ENGINEERING OVER CHECKLISTS

Reliability is a feature.

Bounded resource use, failure-aware APIs and repeatable tests come before breadth.

01 /

Bounded data

Scene records, file IO, CPU textures and event queues have explicit limits and validation.

02 /

Portable builds

CMake and C++20 target Linux, macOS, Windows and Android arm64 native-core CI.

03 /

Tests & sanitizers

CTest, package-consumer coverage and AddressSanitizer/UBSan help guard regressions.

04 /

Supply-chain hygiene

SDL is checksum-pinned, workflow actions are pinned by commit, and the default core stays lean.

BUILD IT LOCALLY

Start with the core.

You need CMake 3.25+ and a C++20 compiler. The default configuration does not fetch third-party runtime code.

Full build instructions ↗
TERMINAL / CORE BUILD
cmake -S . -B build -DSTORM_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure

The optional SDL3 demo is a separate desktop target. It is not an Android APK or production renderer.
