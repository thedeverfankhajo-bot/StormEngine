## Graphics API notes

Android now has an initial Vulkan 1.0 clear-and-present path with an API 24 minimum for this host target; availability still depends on the actual device/GPU and the current implementation has no non-Vulkan fallback or device-loss recovery. iOS now has a native Metal clear-and-present path through CAMetalLayer. Neither smoke path renders SpriteBatch/Scene geometry or establishes physical-device compatibility. Vulkan on iOS would require a translation layer such as MoltenVK and must not be described as native iOS Vulkan support.

References:

- [Android Developers: Use Vulkan for graphics](https://developer.android.com/games/develop/vulkan/overview)
- [Vulkan Guide: Platform support](https://docs.vulkan.org/guide/latest/platforms.html)
- [Apple Developer: Metal](https://developer.apple.com/documentation/metal)

## Validation rules

- Planned: no implementation exists.
- Experimental: implementation exists but interfaces, behavior, or compatibility are not stable.
- Implemented: source code exists.
- Tested: relevant automated tests passed in the stated environment. Cross-compilation is recorded separately from runtime testing.
- Verified: target runtime behavior was validated on named physical devices and OS versions.
- Unsupported: intentionally not supported by the product.

The project currently has no Android- or iOS-verified runtime features. The main-branch CMake configuration registers 27 host CTest executables; the latest CI result for any change must be checked before claiming they pass. The Android job cross-compiles arm64-v8a targets at API 24, builds the Vulkan NativeActivity bridge, assembles an arm64 debug APK, and verifies native-library packaging; the iOS job cross-compiles device arm64 targets and produces an unsigned iOS `.app` bundle with the Metal presentation host. These are host-test, target-build, and package checks only. They do not prove runtime behavior on a physical device, actual sustained GPU presentation, signed release output, AAB/IPA export, or a complete game-engine runtime.
